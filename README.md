# GitHub 项目详细信息与提交分布可视化分析报告工具

一款轻量、高效且美观的 GitHub 项目全景分析与提交分布可视化工具。基于 GitHub REST API 自动抓取指定账号下的所有原创仓库（包含公开与私有项目，排除 Fork 仓库），对代码提交历史、作息规律、语言分布及项目影响力进行多维度深度统计，并生成具备交互式图表与暗黑/浅色主题支持的单文件 HTML 仪表盘报告。

---

## ✨ 核心特性

- 📊 **全量仓库盘点与指标聚合**：
  - 自动获取原创仓库列表，提取创建时间、最新推送时间、Star 标星数、Fork 分支数、代码体积、主语言、公开/私有状态等详细元数据。
  - 统计各项目在默认分支上的全量提交数，并精准区分并对比**本人提交**与**全员提交**。
- ⏱️ **多维提交行为与作息分析**：
  - **24 小时活跃时段分布**：揭示一天中的核心编码时段与作息习惯。
  - **星期活跃度分布**：对比工作日（周一至周五）与周末（周六/周日）的提交节奏。
  - **星期 × 24小时 打卡热力气泡图 (Punchcard)**：GitHub 经典打卡矩阵，气泡大小与透明度联动反映时间与日期的提交密集度。
  - **分年度提交贡献日历 (Contribution Calendar)**：类似 GitHub 主页贡献日历，支持年份 Tab 按钮自由切换各年份，每日色块按提交数量智能映射 4 级颜色深度，并支持联动“本人/全员”数据。
  - **历年月度提交活跃趋势 (Timeline)**：长期代码活跃趋势折线图，支持 DataZoom 时间轴拖拽缩放漫游。
  - **编程语言占比分布**：南丁格尔/环形饼图呈现语言覆盖与仓库数量。
  - **仓库综合影响力排行 Top 10**：按提交量展示主要活跃贡献项目。
- 🖥️ **交互式现代化 HTML 仪表盘**：
  - **主题无缝切换**：支持 GitHub 经典暗黑模式（Dark Mode）与优雅浅色模式（Light Mode）。
  - **动态视角切换**：一键切换“本人提交”与“全员提交”，图表即时联动重绘。
  - **可检索/排序列的仓库明细表格**：支持仓库名、描述与语言实时模糊搜索；支持**创建年份下拉选择器（按年份精准过滤）**；支持公开/私有属性过滤；支持**单页条数自由切换（15、30、50、100 条/页）**；支持点击表头对 Stars、Forks、提交数、大小及日期进行双向排序。
  - **单文件便携交付**：图表通过 Apache ECharts 5 渲染，报告为完全独立的单文件 HTML，双击即可在任何现代浏览器中打开。
- ⚡ **高性能并发抓取与智能持久化缓存**：
  - 内置多线程并发采集（默认 6 线程），大幅缩短 API 抓取耗时。
  - 智能增量缓存：根据各仓库的 `pushed_at` 时间戳校验，无新推送的仓库直接命中本地缓存，二次运行仅需不足 1 秒。

## 🚀 快速开始

### 1. 环境准备

- Python 3.9 及以上版本
- 安装依赖库：
  ```bash
  pip install -r requirements.txt
  ```

### 2. GitHub 身份认证

工具支持以下任意一种认证方式（优先级自上而下）：

1. **命令行参数**：`--token <your_github_token>`
2. **环境变量**：`GITHUB_TOKEN` 或 `GH_TOKEN`
3. **GitHub CLI (推荐)**：若本机已安装并登录 `gh`（如通过 `gh auth login`），工具会自动提取当前登录凭证，无需任何手动配置。

### 3. 执行分析并生成报告

在项目根目录下直接运行：

```bash
python main.py
```

执行完毕后，控制台将输出摘要指标，并在当前目录下生成 [`github_report.html`](file:///D:/MyCodingProjects/my-github-projects/github_report.html)。直接在浏览器中打开该文件即可查看完整可视化仪表盘。

---

## 🛠️ 命令行参数说明

| 参数 | 类型 | 默认值 | 作用说明 |
| :--- | :--- | :--- | :--- |
| `--token` | 字符串 | 自动读取 | 指定 GitHub Personal Access Token |
| `--output` | 字符串 | `github_report.html` | 生成的 HTML 报告输出路径 |
| `--refresh` | 标志 | 关 (`False`) | 强制跳过本地缓存，从 GitHub API 重新抓取全量数据 |
| `--workers` | 整数 | `6` | 并发同步仓库提交记录的线程数 |
| `--tz` | 整数 | `8` | 分析时区偏移量（小时数），默认为 `8`（中国标准时间 UTC+8） |

### 示例操作

- **强制从 GitHub API 刷新最新数据**：
  ```bash
  python main.py --refresh
  ```

- **指定输出报告文件名**：
  ```bash
  python main.py --output output/my_github_analytics.html
  ```

- **使用指定的 GitHub Token**：
  ```bash
  python main.py --token ghp_xxxxxx
  ```
